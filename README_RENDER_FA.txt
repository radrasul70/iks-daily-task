سامانه دیلی‌تسک بازرگانی – نسخه نمایشی مدیریتی ۱۹
شرکت ایمن خودرو شرق

این بسته بر پایه آخرین فایل v18.1 موجود تهیه شده و فقط تنظیمات لازم برای میزبانی آزمایشی روی Render، مسیر ذخیره‌سازی پایدار و کوکی امن پشت پراکسی HTTPS را اضافه می‌کند.

این بسته انتشار خودکار روی حساب Render شما را انجام نمی‌دهد. برای انتشار، باید فایل‌ها را در یک مخزن خصوصی GitHub قرار دهید و آن مخزن را از Render متصل کنید. راهنمای گام‌به‌گام در RENDER_GUIDE_FA.txt است.

ورود اولیه در Render:
نام کاربری: admin
رمز عبور: مقداری که هنگام ساخت سرویس برای متغیر INITIAL_ADMIN_PASSWORD وارد می‌کنید.

مهم:
- این نسخه برای نمایش و آزمایش با اطلاعات ساختگی است، نه بهره‌برداری عملیاتی.
- تا تأیید واحد IT، اطلاعات واقعی یا محرمانه شرکت را وارد نکنید.
- تنظیم Render یک دیسک پایدار ۱ گیگابایتی می‌خواهد و بنابراین به طرح پولی سازگار با Persistent Disk نیاز دارد.
- نشست‌های کاربران با Restart/Deploy ممکن است منقضی شوند و نیاز به ورود مجدد داشته باشند.
- نسخه نهایی سازمانی پس از دریافت مشخصات VM و بازبینی امنیتی IT آماده خواهد شد.
